# CrossyRoad

Um jogo simples inspirado no Crossy Road, desenvolvido em C utilizando Raylib.

## Objetivo

Este projeto foi criado para praticar:

- Programação em C
- Desenvolvimento de jogos
- Estruturas de dados
- Organização de projetos
- Git e GitHub
- Lógica de jogos

## Tecnologias

- C
- Raylib
- Git
- GitHub
- VS Code

## Funcionalidades Planejadas

- [ ] Movimentação do jogador
- [ ] Sistema de grid
- [ ] Carros em movimento
- [ ] Colisão
- [ ] Sistema de pontuação
- [ ] Sprites
- [ ] Game Over

## **Como compilar:**

  ### Linux:

  1. Clone o repositorio do projeto:

  ```bash
  git clone https://github.com/guilhermeblacerda/CrossyRoad.git

  ```

  2. Na pasta raiz do projeto faça o `make`:
    
  ```bash
  make
  ```

  3. Rode o projeto:

  ```bash
  ./main
  ```
  ### Windows:

  1. Clone o repositorio do projeto: 
  ```bash
  git clone https://github.com/guilhermeblacerda/CrossyRoad.git
  ```

  2. Na pasta raiz do projeto, compile-o:
  ```bash
  make
  ```
  3. Rode o projeto:
  ```bash
  main.exe
  ```
